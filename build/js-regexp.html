Выражения

Основное

  • \d - любая десятичная цифра
  • \D - любой символ, кроме десятичной цифры
  • \s - любой пробельный символ
  • \S - любой непробельный символ
  • \w - любой символ, образующий "слово"
  • \W - любой символ, необразующий "слово"
  • \b - граница слова
  • \B - не граница слова
  • \A - начало данных (независимо от многострочного режима)
  • \Z - конец данных, либо позиция перед последним символом строки, в случае если это символ перевода строки (независимо от многострочного режима)
  • \z - конец данных (независимо от многострочного режима)
  • [] - символьный класс
  • () - подмаска
  • | - разделитель альтернативных масок
  • {m,n} - квантификатор повтора: min m, max n раз
  • (?:) - незахватывающая подмаска
  • (?=x) - положительное утверждение
  • (?!x) - отрицательное утверждение

Expression Flag

  • //g - global (все совпадения)
  • //i - case insensitive (регистронезависимый поиск)
  • //m - multiline
  • //u - unicode
  • //y - sticky

Символы

  • \f - символ разрыва страницы
  • \t - символ табуляции
  • \v - символ вертикальной табуляции
  • \r - символ возврата каретки
  • \n - символ перевода строки
  • \xhh - символ с кодом hh
  • \uhhhh - символ юникод с кодом hhhh

Специальные символы

  • \ - для обычных символов - делает их специальными. Например, выражение /s/ ищет просто символ 's'. А если поставить \ перед s, то /\s/ уже обозначает пробельный символ. И наоборот, если символ специальный, например *, то \ сделает его просто обычным символом "звездочка". Например, /a*/ ищет 0 или больше подряд идущих символов 'a'. Чтобы найти а со звездочкой 'a*' - поставим \ перед спец. символом: /a\*/.
  • ^ - начало ввода (или линии, в многострочном режиме); отрицание в [],
  • $ - конец ввода (или линии, в многострочном режиме)
  • * - соответствует предыдущему символу повторенному 0 или более раз. Эквивалентно {0,}. Например, /bo*/ соответствует 'boooo' в "A ghost booooed" и 'b' в "A bird warbled", но не в "A goat grunted".
  • + - соответствует предыдущему символу повторенному 1 или более раз. Эквивалентно {1,}. Например, /a+/ соответствует 'a' в "candy" и всем символам 'a' в "caaaaaaandy".
  • ? - соответствует предыдущему символу повторенному 0 или 1 раз. Эквивалентно {0,1}.
  • . - (десятичная точка) соответствует любому символу кроме переноса строки. Например, /.n/ соответствует 'an' и 'on' в "nay, an apple is on the tree", но не 'nay'.

Примеры

const regexp = /[a-zA-Z]/g; const str = "Привет. You have 23 likes"; console.log(regexp.test(str));

Символы

Цифры

› "23"

🟢 /[\d]/ # все цифры в диапазоне 0-9 🟠 /[\D]/ # символы кроме цифр в диапазоне 0-9 🟢 /[0-4]/ # цифры в диапазоне 0-4 🟠 /[^0-4]/ # символы кроме цифр в диапазоне 0-4

Символы

› "Hello, Tony!"

🟢 /[\s]/ # пустые символы (пробелы, табуляция, перенос строк) 🟢 /[\S]/ # все не пустые символы 🟢 /[,]/ # символ запятая "," 🟠 /[.]/ # символ точка "." 🟢 /[\w]/ # символы, являющиеся буквами или цифрами 🟢 /[\W]/ # символы, НЕ являющиеся буквами или цифрами 🟢 /./ # любой символ кроме переноса строк 🟠 /\./ # символ "." (экранирование) 🟠 /[.]/ # символ "." (символьный класс)

Буквы

› "Привет. You have 23 likes"

🟢 /[a-zA-Z]/ # любая EN буква в любом регистре 🟢 /[а-яА-Я]/ # любая RU буква в любом регистре

Комбинации

› "Привет. You have 23 likes"

🟢 /[a-zA-Zа-яА-Я]/ # любая RU / EN буква 🟢 /[a-zA-Z]/g # любая EN буква - глобальный поиск 🟢 /[a-zA-Z.,]/ # любая EN буква / символ "," / символ "." 🟢 /[a-zA-Zа-яА-Я.,-\d\s]/ # любая EN/RU буква, символы '.,-', цифры 0-9, пустые символы

Поиск по словам

› "О дивный новый Мир"

🟠 /^новый/ # поиск с начала строки 🟢 /^О дивный/ # поиск с начала строки 🟠 /О дивный$/ # поиск с конца строки 🟢 /Мир$/ # поиск с конца строки 🟢 /^О дивный новый Мир$/ # точное совпадение: начало и окончание 🟠 /[^(^О дивный новый Мир$)]/ # точное совпадение (отрицание) 🟢 /новый(?= Мир)/ # слово "новый" после которого ЕСТЬ пробел и слово "Мир" 🟠 /новый(?! Мир)/ # слово "новый" после которого НЕТ пробела и слова "Мир"

› "hello"

  • Кол-во любых символов между буквами "h" и "o"
🟢 /h.{3}o/ # 3 символа 🟠 /h.{4,7}o/ # диапазон 4-7 символов 🟢 /h.{2,}o/ # от 2 и более символов 🟢 /h.+o/ # от 1 и более символов 🟢 /h.*o/ # 0 и более символов

Операторы

› "О дивный новый Мир"

🟢 /новый|старый/ # оператор "или" ("новый" или "старый") 🟠 /[^(О дивный новый Мир)]/ # отрицание 🟠 /\./ # символ "." (экранирование)

Регистр

› "О дивный новый Мир"

🟢 /Мир/ # регистрозависимый поиск 🟠 /мир/ # регистрозависимый поиск (несовпадение регистра) 🟢 /мир/i # регистроНЕзависимый поиск
